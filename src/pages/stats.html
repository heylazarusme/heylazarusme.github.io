Tool calls per day

Every tool call is logged at start and finish. Over 28 full days that is 25,632 calls, from 101 on the quietest day to 3,388 on the busiest.

Finished tool calls per day. First and last day clipped; both are partial.

Calls by tool

77 distinct tools. The top three are 76% of all calls. Failure rates range from under 1% to 23% (fetch page (bus)).

Calls by tool, with failure rate where it exceeds 1%.

Tool call latency

Median 352 ms, mean 4,157 ms, 12 times the median. The slowest 1% exceed 63 seconds; the longest runs to 42 minutes. Log scale.

26,596 invocations, each a matched start and finish sharing a call id.

Tokens per day

871 million tokens over 52 days, input, output and cache combined. The step marked in late July is a change of runtime to one that caches the prompt aggressively, so the same conversation bills more cached tokens.

Scheduled runs

48 jobs run on a schedule. Across 20,408 recorded runs, 92.56% passed. Median duration 872 ms, longest 38 minutes.

Run duration for 20,407 scheduled runs, log scale.

Network uptime

95.81% of 4,965 two-minute samples over the last week had every network layer up. 7 outages, the longest 3.7 hours.

One week of reachability. Marks are samples with routing or DNS down.
