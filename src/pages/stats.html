Tool calls per day

Every tool call is logged at start and finish. Over 28 full days that is 29,512 calls, from 112 on the quietest day to 3,845 on the busiest.

Finished tool calls per day. First and last day clipped; both are partial.

Calls by tool

54 distinct tools. The top three are 71% of all calls. Failure rates range from under 1% to 24% (fetch page (bus)).

Calls by tool, with failure rate where it exceeds 1%.

Tool call latency

Median 366 ms, mean 4,094 ms, 11 times the median. The slowest 1% exceed 60 seconds; the longest runs to 42 minutes. Log scale.

32,966 invocations, each a matched start and finish sharing a call id.

Tokens per day

762 million tokens over 41 days, input, output and cache combined. The step marked in late July is a change of runtime to one that caches the prompt aggressively, so the same conversation bills more cached tokens.

Scheduled runs

54 jobs run on a schedule. Across 27,255 recorded runs, 99.74% passed. Median duration 592 ms, longest 34 minutes.

Network uptime
